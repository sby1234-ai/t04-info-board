# 과제5 고정 검사 10개 (작업 시작 전 고정, 이후 삭제·완화·기대값 변경 금지)

대상 기능: 환율판(과제4)에 "최근 통계 카드" 추가 — 보유한 일별 기록 중 최근 최대
7건(하루 1건이므로 최대 7일치)의 **최고값·최저값·평균값**을 상단 카드 아래 새 카드로
보여준다. 값은 저장된 `data/daily.json`의 raw records에서 화면 로드 시마다 즉석
재계산한다(캐시된 필드를 별도로 저장하지 않는다).

새 순수 함수: `computeRecentStats(records, { maxDays = 7 } = {})` — `scripts/lib.mjs`에 추가.
입력 `records`는 `{date, value, ...}` 형태의 배열(하루 1건으로 이미 정리된 상태 가정).

## 로직 검사 (S01~S05) — Node로 네트워크 없이 실행

| ID | 입력 | 기대값 |
|---|---|---|
| S01 | `computeRecentStats([])` | `null` |
| S02 | `computeRecentStats([{date:"2026-09-10",value:1339}])` | `{count:1, min:1339, max:1339, avg:1339}` |
| S03 | `computeRecentStats([{date:"2026-09-10",value:1339},{date:"2026-09-11",value:1345.06}])` | `{count:2, min:1339, max:1345.06, avg:1342.03}` |
| S04 | 날짜 2026-09-01~09-09(9건), value가 날짜 순서대로 1~9 | `{count:7, min:3, max:9, avg:6}` (최근 7건 = 09-03~09-09, 즉 오래된 2건 제외) |
| S05 | `[{date:"2026-09-10",value:100},{date:"2026-09-10",value:200}]` (같은 날짜 중복 방어 케이스) | `{count:1, min:200, max:200, avg:200}` (같은 날짜는 마지막 값 하나로 취급, 죽지 않아야 함) |

avg는 소수 둘째 자리에서 반올림.

## 화면 검사 (S06~S09) — Playwright로 실제 페이지에서 확인

| ID | 확인 방법 | 기대값 |
|---|---|---|
| S06 | 정상 데이터로 페이지 로드 | 상단 환율 카드 아래에 "최근 통계" 카드(예: `#recent-stats`)가 나타난다 |
| S07 | 그 카드의 텍스트 확인 | 최고값·최저값·평균값 레이블 3개와 "KRW per 1 USD" 단위 텍스트가 모두 보인다 |
| S08 | `data/daily.json`에 기록이 1건뿐인 상태로 로드 | 카드 제목/문구가 정확히 "최근 1일 기준"이라고 표시된다(7일이라고 거짓 표시 금지) |
| S09 | `data/daily.json`의 raw 값을 임의로 바꾼 뒤 새로고침 | 화면 통계(min/max/avg)가 그 raw 값에서 즉석 계산한 값과 일치한다(별도 캐시 필드 없음 확인) |
